# ⚡ VIRAL ARCADE — 10 Retro Cyber Mini-Games

A sleek, responsive, zero-dependency Arcade Website featuring **10 highly addictive, viral mini-games** engineered with HTML5, CSS3 Glassmorphism, Canvas 2D, and procedural Web Audio API synthesis.

---

## ✨ Features & Architecture

- **Zero External Dependencies**: Works out-of-the-box in any modern browser by simply double-clicking `index.html` or launching a local server.
- **Procedural Audio Synthesizer**: Pure Web Audio API sound design (no missing audio assets, no latency, full mute toggle).
- **Global Arcade Economy**:
  - Earn **Arcade Coins** across all games.
  - Player Level & XP progression bar.
  - 14 unlockable Trophies / Achievements with rewards.
- **Unlockable Visual Themes**:
  - Cyberpunk Neon (Default)
  - Synthwave '84 (Violet & Sunset Gold)
  - Matrix Terminal (Phosphor Emerald)
  - Laser Crimson (Hyper Red)
  - Void OLED (Pure Obsidian & Ice Blue)
- **Daily 2x Coin Challenge**: Deterministic rotating daily game with 2x coin bounty.
- **Surprise Me! Roulette**: Interactive spinning neon roulette that picks a random game.
- **Viral Share Generator**: Generates formatted challenge messages with emojis, one-click copy, and share links for X/Twitter & WhatsApp.
- **Fully Responsive**: Adapts automatically to Desktop, Tablet, and Mobile screens with dedicated touch controls.

## 🚀 How to Run

### Method 1: Direct File Launch
Double click `index.html` in your browser.

### Method 2: Python Local Server
```bash
python -m http.server 8080
```
Then open `http://localhost:8080` in your web browser.
